Implementing DSP blocks from first principles

This is a reading guide to dspkit, a NumPy library where every filter, transform and rate changer is written out explicitly. Each chapter covers the algorithm, what the code means line by line, the numerical pitfalls, and how the block is verified. Signals-and-systems fundamentals are assumed.

CHAPTER 01

Filtering core

dspkit/core.py · lfilter, fir_filter, convolve, freqz, sosfreqz, group_delay, tf2zpk, zpk2tf

Direct Form II Transposed

lfilter is the template for every recursive structure in the package. It runs the general difference equation using K = max(M, N) state registers, which is the minimum possible (a canonical realisation).

difference equation (a0 = 1) y[n] = ∑k=0M bk x[n−k] − ∑k=1N ak y[n−k]
DF2T state update, per sample y = b0x + s0     si = bi+1x − ai+1y + si+1   (i = 0 … K−2)     sK−1 = bKx − aKy

The two z⁻¹ registers hold partial sums. In hardware the critical path from x to y is a single multiply and a single add, regardless of order, because the long adder chain is broken up by registers. This is the main reason transposed forms are the default for FIR filters on FPGAs.

  1. normalize_tf divides both vectors by a[0]. Every recurrence after this point assumes a0 = 1.
  2. b and a are zero-padded to the same length K+1, so one uniform update covers FIR (a = [1]) and all-pole (b = [b0]) filters alike.
  3. s is the complete filter state. It is either zeros (filter at rest) or the caller's zi. Nothing else carries memory between samples.
  4. yn = b[0]*xn + s[0]: the output depends on the current input and only one register.
  5. s[:-1] = b[1:K]*xn - a[1:K]*yn + s[1:]: NumPy evaluates the whole right-hand side before it assigns anything, so every register updates "on the same clock edge". If you write this as a Python loop going downward over i, you overwrite s[i+1] before it has been read. That is the classic bug.
  6. The last register has no successor, so it gets no + s[K] term.
  7. The function returns s as zf. Its layout matches SciPy's zi, so the two can be used interchangeably.

Streaming FIR and the history convention

  1. The state is the last M inputs, newest first. This is the contents of an M-register tapped delay line.
  2. xe = history (oldest first) followed by the new block, so xe[M+n] == x[n] and tap k reads xe[M+n-k].
  3. The loop runs over taps, not samples. Each iteration is one vector multiply-add of a delayed copy of the input, so the cost is O(N·L) with only N NumPy calls.
  4. zf = xe[::-1][:M] returns the M most recent inputs in the same order the function expects for zi.

Frequency response and group delay

freqz evaluates H on the unit circle directly. It builds the matrix E[i,k] = e−jωik and computes two matrix–vector products. That costs O(F·N), which is fine for analysis and is exact at any frequency you choose, with no FFT grid. group_delay avoids differentiating the unwrapped phase numerically by using an identity:

group delay of a polynomial P(z) = ∑ pk z−k τP(ω) = Re{ ∑ k pk e−jωk / ∑ pk e−jωk }      τH = τB − τA
  1. tau(p) is the identity above. k * p is the coefficient vector of −z·dP/dz.
  2. Where P(ejω) = 0 (a zero on the unit circle, e.g. Butterworth zeros at z = −1), the ratio is 0/0. errstate suppresses the warning and the caller has to mask those frequencies. The tests and the example plots do this.
Pitfalls
  • zpk2tf with fewer zeros than poles: dspkit prefixes b with zeros to keep the exact delay z−d. scipy.signal.zpk2tf does not, so the magnitude is the same but the phase differs by d samples.
  • The Python-level loops run at about 1 µs per sample per section. Use them to learn and verify; use scipy.signal for real-time throughput in stage 2.
CHAPTER 02

FIR design

dspkit/fir.py · get_window, firwin, kaiserord, freq_sampling, firls, remez

The module has five design methods, ordered from heuristic to optimal. All of them return symmetric taps (linear phase). The test case used throughout this chapter is: fs = 48 kHz, passband 0–6 kHz, stopband 8–24 kHz, ≥ 60 dB attenuation, ≤ 0.1 dB passband ripple.

TypeNSymmetryForced zerosUse
Ioddsymmetricnoneany response; required for highpass and bandstop
IIevensymmetricH(π) = 0lowpass, bandpass
IIIoddantisymmetricH(0) = H(π) = 0Hilbert transformer, differentiator
IVevenantisymmetricH(0) = 0differentiator

1 · Window method

The ideal multiband response is a sum of rectangular passbands [l, r] (normalised to Nyquist). Its inverse DTFT is a difference of sincs, centred at m = n − (N−1)/2 so the filter is causal and linear-phase.

hideal[m] = ∑bands [ r sinc(r m) − l sinc(l m) ],    sinc(x) = sin(πx)/(πx)      h[n] = hideal[m] · w[n]
  1. Cutoffs are divided by fs/2, so all the internal maths uses Nyquist = 1.
  2. edges = [0, c0, c1, …, 1]. Alternate intervals are passbands, and pass_zero chooses whether the first one is a passband. This one rule covers lowpass, highpass, bandpass, bandstop and multiband filters.
  3. A passband that reaches Nyquist with even N would be Type II, which has a forced zero at π, so the function rejects it.
  4. m is centred, so h is exactly symmetric. Each passband adds its sinc difference.
  5. Scaling: for a symmetric FIR, |H(f0)| = |∑ h[n] cos(π m f0)| because the sine terms cancel in pairs. The function normalises gain to 1 at DC, at Nyquist, or at the centre of the first passband, which matches SciPy's scale=True.

2 · Kaiser design formulas

β = 0.1102(A−8.7)  (A > 50),   0.5842(A−21)0.4 + 0.07886(A−21)  (21 < A ≤ 50)      N − 1 = (A − 7.95) / (2.285 Δω)

kaiserord(60, 2000, fs=48000) returns 89 taps with β = 5.65. Measured, the design reaches 59.2 dB, which misses the 60 dB target. The formula is an empirical fit, so always measure the result and add taps if it falls short.

  1. Power series for I0. Each term is the previous term times (x/2)2/k2, which avoids computing factorials and overflowing.
  2. 40 terms are enough for the arguments a Kaiser window uses (β < 15). For large arguments use the asymptotic expansion instead.

3 · Frequency sampling

You specify the amplitude at N equispaced frequencies ωk = 2πk/N. Attaching linear phase and taking the inverse DFT of a real, symmetric amplitude gives:

h[n] = (1/N) [ A0 + 2 ∑k=1L Ak cos(ωk(n − L)) ],    N = 2L+1

The response passes through the samples exactly and ripples between them. One intermediate "transition sample" (T1 ≈ 0.39) lowers the first sidelobe by about 20 dB. remez also uses this function as its last step, converting the optimal amplitude into taps.

4 · Weighted least squares

Write the Type I amplitude as a cosine series and fit it to the desired response on a dense grid. Least squares is linear, so the solution is a single solve.

A(ω) = ∑k=0L ak cos(kω)     min ∑i Wi (A(ωi) − Di)2  ⇒  (CTWC) a = CTWD,   Cik = cos(kωi)
  1. C is the design matrix, with one row per grid frequency and one column per cosine.
  2. Multiplying each row and the target by √Wi converts weighted LS into ordinary LS. lstsq uses SVD, which is better conditioned than forming CTWC.
  3. Coefficients to taps: h[L] = a0 and h[L±k] = a_k/2, because ak cos(kω) = (ak/2)(ejkω + e−jkω).
  4. The grid accepts any desired D. multirate.cic_compensator reuses this function with D = 1/|HCIC|.

5 · Parks–McClellan (Remez exchange)

Remez minimises the maximum weighted error. By the alternation theorem, the optimum has at least L+2 frequencies where the error reaches ±δ with alternating sign. The algorithm repeatedly guesses those frequencies, solves for δ, and moves the guesses to the actual error peaks.

closed-form ripple for a trial extremal set {xk = cos ωk} δ = ∑ bk Dk / ∑ bk(−1)k/Wk,    bk = 1 / ∏i≠k(xk − xi)     Ck = Dk − (−1)kδ/Wk
  1. Grid. _band_grid samples only the bands; transition bands are "don't care" regions. Grid spacing is 1/(16N). Using x = cos ω turns A(ω) into an ordinary polynomial of degree L in x.
  2. Initial guess. L+2 indices equally spaced over the grid.
  3. Solve δ. _bary_weights gives bk. The δ formula is the closed-form solution of the (L+2)×(L+2) system, so no matrix is ever formed.
  4. Interpolate. A polynomial of degree L is fixed by L+1 points, so the last extremal is dropped and A is evaluated on the whole grid with barycentric Lagrange (_bary_eval). This is O(grid · L) and numerically stable.
  5. Exchange. _find_extrema collects local extrema of E within each band, with band edges always counted. It keeps the larger of any same-sign neighbours so the signs alternate, then trims from the ends down to L+2.
  6. Stop when max|E| equals |δ| to 1 ppm, or when the extremal set stops changing. This usually takes 6 to 12 iterations.
  7. Taps. Sample A at ωm = 2πm/N and call freq_sampling, which is an exact inverse for a degree-L cosine series.

Pitfalls
  • Band edges are in units of fs. With the default fs=2, 1.0 is Nyquist. With SciPy's remez default (fs=1), Nyquist is 0.5.
  • Remez fails to converge, or rings badly in the transition band, when the transition is too narrow for N, when N is above about 500 (barycentric weights underflow), or when the bands are so wide that no don't-care region is left.
  • Transition bands are unconstrained. Always plot the full response, not just the bands.

Bandpass and bandstop filters double the order. butter(4, [.2, .4], 'bandpass') is 8th order. ω0 is the geometric centre √(Ω1Ω2) of the pre-warped edges.

Bilinear transform

s = 2fs (z − 1)/(z + 1)  ⇔  z = (2fs + s)/(2fs − s)      Ω = 2fs tan(ω/2)
  1. Each finite root maps by z = (2fs+s)/(2fs−s). The left half-plane maps inside the unit circle, so stability is preserved.
  2. The d zeros at s = ∞ land at z = −1 (Nyquist). This is why every bilinear lowpass has an exact null at fs/2.
  3. The gain is fixed by matching the leading coefficients: kd = k ∏(2fs−z)/∏(2fs−p).
  1. The edges are normalised to Nyquist. The internal bilinear rate is fixed at fs′ = 2 (Nyquist = 1), so warped = 4 tan(πWn/2). The final digital filter does not depend on fs′, because it cancels between the pre-warp and the transform.
  2. Bandpass and bandstop take bandwidth = the difference of the warped edges and centre = their geometric mean.
  3. The output is 'sos' by default. 'ba' exists only for teaching; see Part B of ex02.

Second-order sections

  1. to_groups splits the roots into conjugate pairs and pairs of reals. A single leftover real root is paired with a root at the origin, so a2 = 0 or b2 = 0.
  2. Pole pairs are sorted so the one closest to the unit circle (highest Q) comes first, and each takes the nearest zero pair. Putting a resonant peak in the same section as the zeros that partly cancel it limits that section's gain.
  3. The order is then reversed so the highest-Q section is last. Noise injected early would otherwise be amplified by the resonant sections that follow it, and in fixed point the peaky section is also where overflow risk is highest.
  4. The overall gain k goes into section 0's numerator. In fixed point, spread it across the sections instead (exercise 10).
  1. Section i fully processes the block before section i+1 starts. This is valid because each section is LTI, and the hardware pipeline computes the same result.
  2. The inner loop is the 3-line DF2T biquad: 5 multiplies and 4 adds per sample.
  3. zf has shape (n_sections, 2), the same layout as SciPy.

Why SOS: coefficient sensitivity

ex02 designs an 8th-order Butterworth bandpass from 0.10 to 0.12 and rounds only the feedback coefficients to a 2−16 grid. Those coefficients decide where the poles are.

Pitfalls
  • Rounding b of the direct form in the same experiment sets it to zero, because the gain k ≈ 10−8. Overall gain has to be distributed before quantisation.
  • The DC gain of an even-order Chebyshev I filter is 1/√(1+ε2), not 1.
  • Specify band edges in the units of the fs you pass. Mixing Hz edges with the default fs=2 raises a ValueError, which is better than a silent mistake.
CHAPTER 04

FFT and fast convolution

dspkit/fft.py · dft, fft_recursive, fft, ifft, bit_reverse_indices, rfft_packed, goertzel, fft_convolve, overlap_add, overlap_save, stft

Radix-2 decimation in time

X[k] = E[k] + WNk O[k],    X[k+N/2] = E[k] − WNk O[k],    WN = e−j2π/N
  1. E and O are the half-length DFTs of the even-indexed and odd-indexed samples. The recursion ends at N = 1, where the DFT is the identity.
  2. t = W * O is computed once and used twice. That shared product is the butterfly, and it is why there are only N/2 multiplies per stage.

The iterative version is the structure used in hardware and on microcontrollers: permute the input once into bit-reversed order, then run log2N stages of butterflies in place.

  1. bit_reverse_indices: unrolling the recursion fully leaves the input in bit-reversed order. For N = 8 that is [0, 4, 2, 6, 1, 5, 3, 7].
  2. Stage loop: span m = 2, 4, …, N. In each group of m elements, element j pairs with element j + m/2 using twiddle Wmj.
  3. X.reshape(-1, m) is a view, one row per group, so writing to Xg writes to X. All groups of a stage are handled in one vectorised step.
  4. a must be .copy()'d: the top half is overwritten with a + b before the bottom half needs the old a. In hardware this is the butterfly's input register.
  5. Cost: (N/2) log2N complex multiplies, some of them trivial (W = 1, −j). Radix-4 removes more of those (exercise 13).

Real-input FFT from one half-length complex FFT

z[n] = x[2n] + jx[2n+1]  →  Z = FFTN/2(z)    E[k] = (Z[k] + Z*[N/2−k])/2,   O[k] = (Z[k] − Z*[N/2−k])/2j

This halves the cost for real signals such as audio, images and real ADC streams. stft is built on it.

Goertzel: one bin, one real multiply per sample

  1. The filter 1/(1 − ejωz−1) sampled at n = N−1 gives ejω(N−1)X[k]. Multiplying numerator and denominator by the conjugate pole factor makes the recursion real.
  2. The per-sample loop is s0 = x + c*s1 - s2, with c = 2cosω precomputed: a single multiply.
  3. The complex correction runs once, after the last sample. For detection, use the power form, which needs no complex arithmetic.
  4. k may be non-integer, so you can tune each bin exactly to a DTMF frequency.

Fixed point, bit-true

dspkit/fixed.py · QFormat, quantize, round_shift, handle_overflow, requantize, fir_fixed, fir_acc_bits, biquad_fixed, sos_fixed, sqnr_db, write_mem

This module is the reference model for stage 3. Data is stored as integer codes in int64 and every width is declared. Because the arithmetic here is exactly what the hardware does, your HDL output must match it bit for bit.

OperationResult formatHardware view

Rounding is a choice of bias

  1. v >> s on signed NumPy ints is an arithmetic shift, i.e. floor division by 2s. Dropping wires in hardware does exactly the same thing.
  2. 'round' adds half an LSB of the output (2s−1) before flooring. In hardware this is one adder, or the rounding constant preloaded into the DSP48 accumulator.
  3. 'convergent' checks the discarded bits for the exact halfway case (rem == half) and rounds to the even neighbour.
  4. 'trunc' rounds toward zero by negating, shifting and negating back.

Bit-true FIR and accumulator sizing

  1. The products hk * x are exact in int64: 16×16 bits = 32 bits, far from the 63-bit limit.
  2. If acc_bits is given, the accumulator is wrapped to that width after every add, which models a finite hardware register.
  3. Wrapping is harmless when the final sum fits. Two's-complement addition is arithmetic mod 2W, so intermediate overflows cancel out. The test test_fir_fixed_wrap_accumulator_still_exact proves this.
  4. There is a single requantisation at the end, from nx+nh fractional bits to the output format. That is the only rounding point in the filter.

Bit-true biquad (Direct Form I)

  1. DF-I keeps 4 state words (x1, x2, y1, y2) instead of 2, but all five products go into one wide accumulator with no intermediate rounding. That maps onto a single cascaded DSP48 MAC chain.
  2. The recursion is driven by the saturated output y. DF-II's internal node w[n] = x/A(z) has gain up to 1/min|A|, which for high-Q sections can overflow invisibly.
  3. Coefficients use Q(2,14) because |a1| < 2 for any stable biquad.
  4. Python ints have unlimited precision, so acc is exact. Rounding happens once, at >> n_coef.

Exporting to hardware

  1. One two's-complement hex word per line, which is what $readmemh expects. −1 at 16 bits is written as ffff.
  2. // comment lines are allowed by Verilog's reader. Use them to record the format and how the file was generated.

Multirate and CIC

dspkit/multirate.py · downsample, upsample, polyphase_components, polyphase_decimate, polyphase_interpolate, resample_poly, cic_*
type-1 polyphase decomposition and noble identity H(z) = ∑k=0M−1 z−k Ek(zM),   ek[n] = h[nM+k]      [E(zM)] → ↓M  ≡  ↓M → [E(z)]
  1. E is the taps reshaped to (taps per branch, M) and transposed, so row k = h[k], h[k+M], h[k+2M], …
  2. Branch input xk[m] = x[mM − k]: prepend k zeros, then take every M-th sample. This is the input commutator.
  3. Each branch filter runs at the low rate, and the branch outputs are summed.
  4. Equivalence check: decimate_direct (filter at the full rate, discard M−1 of every M outputs) gives identical samples. Max difference measured: 8.9×10−16.
1032

  1. Each of the L branches filters the original low-rate input, so there are no multiplies by stuffed zeros.
  2. y[k::L] = branch[k] is the output commutator: the branch outputs are interleaved.
  3. To restore amplitude, the prototype must have passband gain L, because zero-stuffing divides the average by L.

CIC: decimation without multipliers

H(z) = [ (1 − z−RM) / (1 − z−1) ]N    |H(f)| = |sin(πRMf) / sin(πf)|N    Bout = Bin + ⌈N log2(RM)⌉
  1. The register width comes from Hogenauer's bound. Every stage uses the same width, i.e. no pruning (exercise 22).
  2. The integrators are cumsum followed by a wrap to B bits. For any DC input they overflow continuously, and that is fine.
  3. The combs run after v[::R], at the low rate, with differential delay M. By the noble identity, the comb z−RM at the high rate becomes z−M at the low rate.
  4. Because every operation is mod 2B and the true output fits in B bits, the wrapped result is exact. The test feeds full-scale DC and checks for exactly (215−1)·RN.
Pitfalls
  • The CIC gain (RM)N is 65536 = 216 here. Discard it with a shift, and choose R and M so that it is a power of 2.
  • Saturation inside the integrators breaks the CIC. Only wrap-around arithmetic gives the exact result.
  • The compensator is designed in output-rate Nyquist units. Output frequency f maps to f/(2R) cycles per input sample.

Writing a new block

Use this skeleton for any block you write for coursework. It has explicit state, a block-wise process, a reference test, and a streaming test. The example implements the RBJ peaking-EQ biquad, which you will need for the live equaliser in stage 2.

mine/peaking_eq.py
import numpy as np


def peaking_eq(f0, gain_db, Q, fs):
    """RBJ cookbook peaking EQ -> one SOS row [b0 b1 b2 1 a1 a2].
    Derived from the analog prototype H(s) = (s^2 + s(A/Q) + 1) / (s^2 + s/(AQ) + 1)
    with a bilinear transform pre-warped at f0."""
    A = 10 ** (gain_db / 40)
    w0 = 2 * np.pi * f0 / fs
    alpha = np.sin(w0) / (2 * Q)
    b = np.array([1 + alpha * A, -2 * np.cos(w0), 1 - alpha * A])
    a = np.array([1 + alpha / A, -2 * np.cos(w0), 1 - alpha / A])
    return np.concatenate([b / a[0], a / a[0]])


class Biquad:
    """Streaming DF2T biquad. All memory is in self.s; process() can be called
    on blocks of any length and gives the same result as one long call."""

    def __init__(self, sos_row):
        sos_row = np.asarray(sos_row, float)
        self.b0, self.b1, self.b2, _, self.a1, self.a2 = sos_row / sos_row[3]
        self.s = np.zeros(2)                      # [s1, s2]

    def reset(self):
        self.s[:] = 0.0

    def process(self, x):
        b0, b1, b2, a1, a2 = self.b0, self.b1, self.b2, self.a1, self.a2
        s1, s2 = self.s                           # load state into locals (fast path)
        y = np.empty(len(x))
        for n, xn in enumerate(x):
            yn = b0 * xn + s1
            s1 = b1 * xn - a1 * yn + s2
            s2 = b2 * xn - a2 * yn
            y[n] = yn
        self.s[:] = (s1, s2)                      # store state back
        return y
tests/test_peaking_eq.py
import numpy as np
import scipy.signal as ss
from mine.peaking_eq import peaking_eq, Biquad

rng = np.random.default_rng(0)


def test_matches_reference():
    sos = peaking_eq(1000, 6.0, 2.0, 48000)
    x = rng.standard_normal(2000)
    assert np.allclose(Biquad(sos).process(x), ss.sosfilt(sos[None, :], x))


def test_block_split_invariance():
    sos = peaking_eq(1000, 6.0, 2.0, 48000)
    x = rng.standard_normal(2000)
    whole = Biquad(sos).process(x)
    bq = Biquad(sos)
    parts = np.concatenate([bq.process(c) for c in np.array_split(x, 7)])
    assert np.array_equal(whole, parts)          # bit-identical, not merely close


def test_spec():
    sos = peaking_eq(1000, 6.0, 2.0, 48000)
    w, H = ss.sosfreqz(sos[None, :], [0, 1000, 23999], fs=48000)
    assert np.allclose(20 * np.log10(abs(H)), [0, 6, 0], atol=0.05)
